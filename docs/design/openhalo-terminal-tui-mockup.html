01

重连是瞬时状态，不是对话内容

只有首次中断进入 Transcript。每次 backoff、倒计时和失败次数都只更新同一条状态，不制造日志瀑布。

Transcript +1 max
Status in-place
Draft retained
02

三层信息语义

  • Transcript：每条内容保留来源 Edge，不把所有输出伪装成同一聊天端。
  • Route：只在协作发生时展示发起端、治理节点与目标端。
  • Edges：Header 仅显示健康摘要，完整设备角色按需展开。
03 OpenHalo product principle

视觉借鉴 CLI 的低噪声，但状态语义保留多设备 Runtime 的独特性。

device → context → presence → action
