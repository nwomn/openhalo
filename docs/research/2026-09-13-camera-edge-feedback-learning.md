# Camera Edge：通过持续反馈提高能力的研究与实现

日期：2026-09-13。用户要求先调研此方向，暂不推进上一轮时序候选验证。本轮只查阅原始论文、作者仓库与部分源文件，没有部署、训练、收集新样本或启动 Runtime 闭环。

## 判断

**有直接相关研究和公开实现。** 对当前“多个低层模型＋MobileVLM V2”组合，最适合先验证的是：反馈绑定视觉证据，积累经确认的个人物品样例，在未来新画面上重新匹配；再用已积累的数据更新轻量分类器或模型。是否改动大模型权重不是系统有没有进步的唯一标准，关键是新场景效果是否提高且旧能力是否保留。

这个方向包括交互式持续学习、少样本增量学习、视觉个性化、主动学习和教师—学生蒸馏。它们覆盖不同问题，不存在本轮已确认可直接替换整个 OpenHalo 管线的一体化方案。尤其“类别识别变好”不自动等于时序过程理解变好。

## 最贴近的研究和实现

| 研究/系统 | 实际机制与实现证据 | 对我们的意义和限制 |
| --- | --- | --- |
| **Socially Guided Continual Learning / cl_hri**，2023预印本、2025期刊版本 | 用户通过界面反复教 Fetch 机器人并测试物品识别；论文有60名参与者、300轮交互。作者公开 ROS/Android/学习服务代码 | 最直接对应“允许初始较弱，通过用户教学成长”。研究也报告遗忘和实际交互中的不可靠性，并非越教越好保证 |
| **CBCL**，上面研究使用的少样本增量方法 | 预训练CNN抽特征，按类别维护特征簇中心，用相近中心投票；添加新知识不必每次重训视觉骨干 | 适合本地样例/原型库基线。特征区分力、错误关联、未知类拒识仍需验证；不是任意物体都教一遍就会 |
| **Tip-Adapter**，ECCV 2022 | 冻结CLIP，用带标签的少量图像构造特征—标签缓存，检索影响分类；有官方代码，另有训练型Tip-Adapter-F | 提供“新增样例立即影响新预测”的实现基础。原任务是少样本分类，不是完整持续学习系统、目标检测或开放集拒识 |
| **R2P**，ICCV 2025 | 从用户提供的概念参考图建立可检索视觉/属性信息，检索后进行个性化识别与问答；官方有建库、检索、模型适配和评估代码 | 适合Runtime管理个人物品知识。论文用MiniCPM-o-2.6及CLIP/FAISS，仓库建议16GB以上RAM；不能声称适配MobileVLM 1.7B或Jetson整套直跑。原实验不是持续多轮纠错学习曲线 |
| **MyVLM**，ECCV 2024 | 外部概念识别头＋学习到的概念嵌入，把用户概念融入VLM表达；有训练与推理实现 | 对“识别我自己的物品并在回答中使用名字”有直接参考意义。需要训练/模型适配；代码标明非商业学术使用限制，不作为已确定产品依赖 |
| **Ekya**，NSDI 2022 | 针对摄像头数据漂移持续微调视觉模型，并分配推理/训练资源；有代码、数据和强模型标注流程 | 支持“快模型运行、后台积累数据再改进”的系统形态，主要是边缘计算服务器资源调度。强模型标签不是人工真值，旧依赖不能原样套到当前Jetson |
| **EdgeCam**，作者公开系统 | README及目录包含低置信帧收集、云端辅助、重训练与模型管理；有edge/cloud程序 | 拓扑上贴近Edge上传证据再更新轻量模型。作者称云结果为ground truth，我们必须保留其伪标签来源；本轮未完成源代码全流程或论文性能复现 |

原始来源：

- SGCL：[论文全文](https://arxiv.org/html/2305.16332v2)、[作者仓库](https://github.com/aliayub7/cl_hri)、[学习服务源文件](https://raw.githubusercontent.com/aliayub7/cl_hri/main/lifelong_learning/lifelong_model_server.py)、[模型封装](https://raw.githubusercontent.com/aliayub7/cl_hri/main/lifelong_learning/cl_model.py)。已看到持久模型加载，以及learn请求执行训练、test请求执行预测。仓库服务列出CBCL/FT/iCaRL，而2025论文比较FT/CBCL/JT；两者不可未经核对就称为同版本完整复现。
- Tip-Adapter：[官方实现与说明](https://github.com/gaopengcuhk/Tip-Adapter)。其少样本缓存与我们当前10秒描述缓存含义不同。
- R2P：[论文](https://arxiv.org/html/2503.18623v2)、[官方实现](https://github.com/Deepayan137/R2P)。fingerprints指用于区分概念的视觉/语义属性，不是生物指纹采集。
- MyVLM：[论文](https://arxiv.org/abs/2403.14599)、[官方实现](https://github.com/snap-research/MyVLM)、[代码许可](https://github.com/snap-research/MyVLM/blob/master/LICENSE)。未确认MobileVLM适配，不把LLaVA家族兼容视作权重可直接互换。
- Ekya：[NSDI正式论文入口](https://www.usenix.org/conference/nsdi22/presentation/bhardwaj)、[官方代码](https://github.com/edge-video-services/ekya)。其golden model标注来源在README明确列出。
- EdgeCam：[作者系统代码与模块说明](https://github.com/MSNLAB/EdgeCam)。本轮确认公开实现存在，不承诺维护状态或本机安装成功。

补充原理参考：[Continual egocentric object recognition，ECAI 2020](https://ecai2020.eu/papers/312_paper.pdf)研究持续物品记忆、新颖性识别及选择性请求用户反馈；本轮未确认可用代码。[JITNet，ICCV 2019](https://openaccess.thecvf.com/content_ICCV_2019/papers/Mullapudi_Online_Model_Distillation_for_Efficient_Video_Inference_ICCV_2019_paper.pdf)用教师分割结果在线训练学生，是具体蒸馏先例，其任务是分割，不是开放式VLM语义学习。

## 我们需要区分的四种变化

| 变化 | 后续得到什么 | 怎样证明 |
| --- | --- | --- |
| 当前目标缓存 | 当前目标有效期内少问一次模型 | 只证明调度/复用，不计入长期能力增长 |
| 经确认的视觉样例/原型库 | 目标离开后再次出现、重启后仍有机会识别 | 在新拍角度/背景/光照上评估；必须排除重复帧和短期缓存 |
| 分类头/适配器/学生权重更新 | 冻结知识库后，模型预测本身发生变化 | 新旧任务独立测试、消融检索；测遗忘和误报 |
| 行为/时序概念学习 | 更可靠理解动作变化和先后关系 | 需要带时间段、目标和动作边界的反馈及新过程测试，单张物品标签不够 |

“这把是我的螺丝刀”首先是实例知识；“螺丝刀这一类都能识别”是更广泛的类别泛化，需要多实例证据。两者应分别保存和验收。

## 建议接入现方案的最小路线：工程推断，未实施

1. **把反馈与样本绑牢。** 每次纠正保存对应ROI/必要整图或片段、帧时间、目标版本、原预测和纠正内容。用户说“不是注射器”只有负标签；明确说“这是螺丝刀”才有相应正标签。目标变化后迟到反馈仍可修正旧样本，但不得覆盖新目标的当前状态。
2. **先新增可持久化的个人视觉样例库。** 经确认样例编码后参与未来ROI匹配，保留unknown/相似物拒识；名称、类别和具体实例分开。已有ImageNet分类器没有可靠拒识能力，不能只在其top-1文字上做替换。固定视觉特征若仍分不开螺丝刀/笔，需换特征或训练，知识库不能凭空产生可分性。
3. **Runtime作为辅助教师和数据管理层。** 强视觉模型查看真实证据并返回候选标签、目标和依据。用户明确纠正是另一种反馈来源。模型间一致不等于真值；教师不确定或与用户反馈冲突时继续留作待核对数据。反馈选择也覆盖部分高置信预测，以捕获我们已见到的高分错误绕过unknown路由。
4. **先量化新画面收益，再决定参数更新。** 数据足够且质量可控时，在具备资源的训练端更新轻量分类头/学生模型，结合旧样本回放减轻遗忘，通过验证后向Edge发布版本。Runtime主机是否有合适训练GPU尚未确认，不预设训练在其常驻服务进程或Jetson中执行。保留可回滚版本；原有推理继续工作。
5. **VLM表达使用有证据的个人知识。** 小模型/检索提供候选和确认状态，MobileVLM负责使用这些信息。若其仍把正确反馈表达错，可单独评估R2P式检索核对或MyVLM式概念适配，不先承诺靠多加几句提示词解决。

建议先做“个人物品学习”，再扩展动作/时序学习；这是可独立验收的增量。用户当前授权的是调研，不据此开始样例收集、上传、训练或Runtime集成。

## 最小验证：教过后是否真的变好

以当前误识别的螺丝刀为首个案例，加入手机、笔、相似细长物和空手负例。给少量明确教学样本，在后续独立拍摄中测试：换角度/背景、放下后再次出现、重启、加入新物品后旧知识是否保留。教学集、阈值校准集、最终测试会话分开；不以连续录像中的近重复帧代替泛化。

固定基线并比较A无学习、B仅当前目标缓存、C经确认样例库、D后续可选参数更新。按累计反馈次数报告曲线：新会话正确率、误认率、unknown比例、有用信息保留、旧物品遗忘、每次确认成本，以及教师调用数/资源消耗。最终测试禁止新的教师或人工提示，否则无法区分“学会了”和“又被代答”。

成功必须同时包含对新图的提升和旧任务不过度退化；响应更自信、回答次数增加、一次命中或缓存复用都不足以宣称持续学习成功。采用教师伪标签的训练组，应由独立人工标注测试，避免把模仿教师错误当作真实准确率提高。以上研究均不保证每轮反馈单调增益。
